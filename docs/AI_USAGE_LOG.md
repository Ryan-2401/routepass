# AI 사용 로그

과제 규칙: 사용한 도구, 주요 프롬프트, AI가 만든 부분을 기록합니다. 이후 작업도 같은 형식으로 아래에 이어서 적으세요.

## 1. 앱 안에서 쓰는 AI (AI INSIDE)

| 기능 | 모델 | 입력 | 출력 | 결과 검증 방법 |
|---|---|---|---|---|
| 도시별 일정·이동수단 후보 | Gemini (Flash 계열, `GEMINI_MODEL`) | 코드가 정한 날짜·구간 틀, 예산, 관심사, 환승 허브 후보 | JSON (일정, 후보, 허브 제안, 팁) | zod 스키마 + 틀 준수 검사, 위반 시 오류를 알려주고 재요청 |
| 운행 여부 판정 | 같은 모델 | 웹 검색 결과 6개 (번호 붙임) | 상태 + 근거 번호 | 번호 범위 검사, 근거 없으면 "확인 불가"로 강제 |
| 식당 선택 | 같은 모델 | OpenStreetMap 실제 식당 목록 (번호 붙임) | 고른 번호 + 이유 | 번호 범위 검사, 실패 시 규칙 기반 선택 |

AI를 일부러 쓰지 않은 곳: 비자·체류일·여행금지 판정(`lib/entry.ts`), 최저가 계산(`lib/pathfind.ts`), 항공 가격.

### 주요 프롬프트 (요약)
- "여행 갈 때 나라를 고르면 AI가 추천 여행지·현지 식당·이동 동선·이동 방법을 정리하고, 유럽 비자 면제 등 출입국 기능도 있는 웹 앱 기획을 짜줘"
- "서울–모스크바–상트–탈린–헬싱키–서울처럼 주면 어디서 며칠 뭘 하고 뭘 먹고 어떻게 이동하는지, 알레그로처럼 중단된 교통편인지도 확인하게 해줘"
- "쉥겐만이 아니라 벨라루스 같은 나라도 넣고, 인천 운항 노선표를 고려해서 AI가 계획을 짜게 해줘"
- "환승편도 찾고 가장 저렴하게 가는 방법도 찾게 해줘"
- "웹 기반 앱을 만들어줘"
